# Art batch 1 (20 images)

**How to use this:** paste each prompt into your image tool. For every prompt marked **[match style]**, attach
`art/backgrounds/wickhollow-square.webp` (the village square from Witch Way) as the style reference. Name each file
with its number, like `01-cottage-inside.png`, zip them all, and send the zip back. High resolution is great; I'll
compress everything.

Three rules apply to every background (1 to 8):

- **Camera:** the same high three-quarter view as the village picture. It looks down at about 30 degrees, straight on
  and not rotated, with no fisheye. The 3D camera in the game copies this angle, so it matters most.
- **Empty:** no people, animals, ghosts or text. The game adds the characters in 3D.
- **Floor:** leave clear open floor in the middle where characters can walk.
